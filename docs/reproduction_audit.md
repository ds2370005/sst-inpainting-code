# 論文再現の実装監査（2026-09-17）

## 後続更新：平均推定器の学習接続

平均推定器を--average-checkpointで読み込み、eval/no_grad/勾配無効で固定して
偏差学習へ接続済み。実データ学習ではチェックポイント必須。
アノマリーローダーも月平均・月平均マスクを返す。観測週平均は基準に使わない。
正規化・時刻間隔等の保存済み設定との整合を確認し、入力への接続と重み不変をテスト。
以下の監査表は更新前の記録を含む。「平均推定器未接続」「引数未対応」の項目は
この更新で解消。人工雲マスク・データ同化・評価の不足は継続。

## 実装済みの基盤

- NetCDF取得コード、時刻索引、対象領域の切り出し、品質・雲フラグ処理。
- 1観測時刻・1区画につき1 NPZ。Celsius/NaN、雲マスク、座標と衛星名を保存。
- 同一座標の9時刻を6時間間隔で読み込み。モデルには[1,9,H,W]を渡す。
- 同時刻の日次観測から7/30日平均、観測数3/5以上の画素を採用。
- 平均推定・偏差生成器、識別器、再構成・敵対的損失、学習CLI、チェックポイント。
- 正規化済みボリュームNPZを使う2段階パッチ推論。
- 形状、学習1バッチ、前処理、マスク、時系列順、座標整合、推論の自動テスト。

## 優先順位付きの差分

| 優先度 | 現状・問題 | 次の対応 |
|---|---|---|
| P0・修正済み | 推論が偏差出力をSST正規化値へ換算せず直接加算。学習の換算と不一致 | 共通関数で2*anomaly_range/(max_temp-min_temp)を学習・推論双方へ適用 |
| P0 | 偏差学習が観測週平均を使用。平均推定モデルをロードしない。--average-checkpointは従来黙って無視 | 凍結した平均推定器の出力を学習で使用し、月平均入力とチェックポイント設定も接続する |
| P0 | 論文式(9)の別観測からの人工雲マスクが実学習に未接続。入力に教師の観測値がそのまま存在 | 訓練集合内の別画像からマスクを選び、入力SSTと入力マスクを同時に隠す。元の教師と教師マスクは保持する |
| P0 | 実ローダーにデータ同化画像がなく敵対的損失が0 | データ同化画像用の独立した読み込み経路を追加。観測との完全な位置・時刻ペアは論文上必須ではない |
| P1 | 欠損週平均は正規化値0に置換。偏差学習がその値を基準にするため、雲なし平均推定と同等ではない | 上記の平均推定器接続で解消し、教師画素の有効性も確認 |
| P1 | 推論CLIはframes形式を直接読めず、正規化済み入力の作成は利用者側に残る | 学習用選別と分離した推論アダプターを追加（曇った対象を推論から除外しない） |
| P1 | 全域1650×1650はモデルの8の倍数・正方形制約に合わない。反復パッチ復元・合成なし | 論文IV-Cの復元手順と境界・重なり処理を設計 |
| P1 | 入力偏差はSST正規化空間の差。±5℃を基準とする偏差正規化にはなっていない | 原著の入力正規化を確認し、モデル・学習・推論を同時に改定 |
| P1 | 再構成損失は全バッチの有効画素数で割るmasked MSE | 論文の画像単位のL2表記とは集約方法が違う。実験設定として明示し、損失重みを同一視しない |
| P1 | 生成器出力はtanh、識別器はゼロpadding。平均枝は時間反復＋追加fusion層 | 本文のclipping/reflect paddingと差分あり。表I〜III・図7/8を画像で確認してから構造変更。重み互換性に注意 |
| P1 | 学習・検証・評価の期間分割、ブイ照合、RMSE/MAE/bias、比較手法、最良モデル選択が未実装 | サンプル索引段階で期間を分け、人工マスクの抽出も訓練期間内に限定 |
| P2 | autocastのみでGradScalerなし。AMPの実GPU検証なし | mixed_precision=falseを維持。CUDAテスト付きで整備 |
| P2 | optimizer状態は保存するがresume CLIなし、依存バージョン未固定 | 再開処理・実験メタデータ・環境固定を追加 |

人工雲マスクは、フィールド名random_cloud_maskがあるだけでは実装済みではない。
現在の汎用AnomalyDatasetは既定でtarget_maskを複製し、実学習ループはそのフィールドを使わない。
また、再構成損失が下がることだけでは、雲の下のSSTを補完できた証拠にならない。

## 意図的な変更・論文からは断定できない箇所

- 固定6×6グリッドは本プロジェクトの選択。論文IV-Bのランダム位置クロップと異なる。
  中央1536×1536のみを保存し、1650×1650の端は含まない。
- 1枚単位NPZとローダーによる時系列組み立ては保存方式の変更。
  同じ値・順序・座標でモデルに渡す限り、手法そのものを変える必要はない。
- 論文はHimawari-8の別期間。現在のH09/2025年データや将来のGCOM-Cは実験条件の変更。
- 論文の二値マスクは観測=1。保存cloud_maskは欠損海域=1で、ローダーで反転＋有限性を判定。
  この変換を経たネットワーク入力の向きは対応する。
- 陸地は雲マスクから除外するがSSTのNaN判定に依存。独立した陸地マスクは保存しない。
  有限値の陸地を確実に除外する処理、出力陸地マスクは今後の改善。原著の具体的方法は不明。
- 雲率の分母は全画素。海域だけの分母にはしていない。原著の分母を未確認のまま変更しない。
- 平均値生成は30日間の全日同時刻ファイルが存在することを要求する独自の厳格条件。
  論文の画素別観測数閾値と、全ファイルの存在条件は別。現在4月単月では4/30のみ平均を生成。
- 識別器のsigmoidをBCEWithLogitsLossに内包すること自体は数値実装上の選択。
  ただし層構成や空間集約が原著と同一かは別途検証が必要。

## 今回の修正と検証

- 偏差の単位換算をsrc/utils/normalization.pyへ共通化し、学習と推論で共有。
- 正規化週平均0（17.5℃）＋偏差出力1（5℃）が22.5℃になる回帰テストを追加。
- --average-checkpointを受け取って無視する挙動を、未対応と分かるエラーへ変更。
- 推論の入力・出力の単位と、新形式NPZを直接受け付けない制限を明記。
- READMEの「データ同化画像は整列ペア必須」と読める説明を修正。
- 旧設計文書に監査文書への案内を追加。既存のモデル構造・固定グリッドは維持。

GPU実学習、サーバーデータ、性能指標は未検証。テスト成功と論文精度の再現は区別する。
推論値は今回の修正で変わるが、保存済み観測NPZとモデルのstate_dict構造は変わらない。
既存チェックポイントを使う場合も、学習時と同じ正規化設定が必要。

## 推奨する次の実装順

1. 平均推定器を偏差学習へ接続し、人工雲マスクの入力・教師分離を実装。
2. 推論アダプターと独立した検証期間を用意し、人工欠損の復元誤差を測る。
3. データ同化画像を導入し、敵対的物理モデル損失を有効化。
4. 原著の図表を逐層照合し、全域復元・ブイ評価・比較実験を整備。
5. ベースラインを固定した後、GCOM-Cへの拡張を別実験として評価。
