# 平原論文の全体識別器による学習

既定の `config.yaml` は局所PatchGANを使用せず、平原論文
「Cloud-Free Sea-Surface-Temperature Image Reconstruction From Anomaly Inpainting Network」
の表IIIの全体識別器を使用する。生成器の構造は変更しない。

## 損失

- 再構成損失は式(3),(4),(7)のマスク付き画像L2ノルムのバッチ平均。画素MSEではない。
- 敵対的損失は式(2)。Gは `mean(log(1-D(fake)))` を最小化する。
- Dは `-mean(log D(real))-mean(log(1-D(fake)))` を最小化する。
- Gの係数は再構成10、敵対的0.1（式(6),(10)およびIV-A-3）。Dの損失には0.1を掛けない。
- 平均段階は月平均項に `1-k/kmax` を掛け、週平均項を加える。
- アノマリー段階は固定した平均生成器の推定週平均に推定偏差を足したSSTを識別する。
- JCOPEの週平均・毎時SSTをそれぞれの段階の実画像に使う。

暫定的な `physical_alpha` と全体・局所の混合係数 `physical_beta` は既定設定から除いた。
旧実験を読み返せるよう、局所識別器のクラスと旧設定の処理は残している。
古い出力フォルダ内の設定を指定すると旧方式が実行されるため、新しい既定設定を使用すること。

## 比較上の制約

局所識別の除去と損失係数の変更を同時に行うため、これは論文の学習設定への変更実験であり、
局所識別だけの影響を切り分ける実験ではない。新しい出力先で初期状態から学習する。
全域復元、データの期間分割、前処理の再監査は今回の変更に含まれない。
論文と同じ復元精度や全処理の完全一致を保証するものではない。
