# GPV水温前処理

`preprocess_gpv.py` はサーバーで実行する独立した前処理です。このPCで実データの処理は行っていません。
必要な依存は `numpy` と `eccodes` です。

## サーバーでの実行

```bash
cd /workspace/sst-inpainting-code
python3 -m pip install numpy eccodes

# 最初は1アーカイブで確認（出力先は空のディレクトリを指定）
python3 data/preprocess_gpv.py \
  --input /datasets/jmagpv/jpn \
  --output /workspace/sst-inpainting-code/data/gpv_check \
  --max-archives 1

# 全アーカイブ、既定海域：北緯19.98–50度、東経117–150度
python3 data/preprocess_gpv.py \
  --input /datasets/jmagpv/jpn \
  --output /workspace/sst-inpainting-code/data/gpv_processed
```

既定はGPV格子の切り出しです。ひまわりと同じ格子にする場合は、前処理済みひまわりNPZ（1次元 `lat` / `lon`）を `--reference-grid /path/to/frame.npz` に指定してください。そのNPZの範囲だけが出力され、`--bounds` は使いません。1パッチのNPZを指定すれば1パッチの範囲になります。全海域を処理するには対象全域の座標NPZを指定してください。最近傍法で再格子化し、元格子の範囲外は欠損にします。マスクをまたぐ補間はしません。

## 読み取り条件

- ファイル名は `Z__C_RJTD_YYYYMMDD000000_OCN_GPV_Rjp_Gll2km_grib2.tar.gz`。
- `Lz1-1000_Psbs_FD01` のみを一時ファイルにコピーします。全体展開はしません。一時ファイルは出力ディレクトリ内に作成し終了時に削除します。
- GRIBの複数フィールド対応を有効にし、変数番号 `(10,4,15)` と実際の水深1mを検査して選択します。先頭フィールドとは限りません。
- UTC初期時刻から0〜24時間の日平均であることを検査します。日付は平均期間の開始日で、終了日ではありません。
- 気象庁仕様に基づきKから273.15を引きます。欠損はNaN、マスクは有効=1です。
- 予報プロダクトです。解析SSTやひまわり表皮水温と同じものとして扱わないでください。
- 仕様: https://www.data.jma.go.jp/suishin/jyouhou/pdf/537.pdf

## 出力

- `daily/YYYYMMDD.npz`: `sst`（℃、H×W）、`valid_mask`、`lat`、`lon`、`metadata_json`。
- `weekly/YYYYMMDD.npz`: 当日を含む連続7日の日平均の平均。同じキーに加えて `valid_day_count`。7日すべて有効な画素だけを有効にします。
- `patches/daily/*.npz`: `assimilation_sst`（1×256×256）。
- `patches/weekly/*.npz`: `assimilation_weekly`（1×256×256）。
- パッチには℃の `sst`、`valid_mask`（1×H×W）、座標、正規化設定、メタデータも保存します。端の256未満の余りは捨て、全欠損パッチは保存しません。
- `report.json`: 処理日、日付欠落、失敗、週平均を作れなかった日、パッチ一覧、有効率、敵対的学習に使用可能な全画素有効パッチのフラグ。

正規化は既存コードと同じ `2*(℃-min_temp)/(max_temp-min_temp)-1`。既定0〜35℃、クリップしません。負の水温は-1未満になり得るため、学習設定も含めた温度範囲の検討が必要です。範囲外画素数はレポートに記録します。欠損の正規化値は0ですが、必ずマスクと一緒に扱います。

## 学習接続の範囲と制約

本コードはGPV前処理のみです。既存の学習ループが期待するキー名・形状を出力しますが、**現在の `--data-root` ローダーへ自動では接続されません**。ひまわり入力との組み合わせ、GPVサンプリング、および識別器の欠損処理は学習側で追加する必要があります。現在の識別器は欠損マスクを使わないため、欠損を0埋めしただけのパッチをそのまま渡してはいけません。レポートの `adversarial_eligible=true` は全画素有効という意味で、科学的な適合性を保証するものではありません。

週平均は7個の連続したFD01から作り、1回の予報のFD01〜FD07を平均しません。欠落日は補間しません。日付欠落監査は処理対象の最初〜最後の範囲のみで、指定期間外の不足は判定しません。学習/検証の分割は別途行い、7日窓による期間の重複にも注意してください。

出力先の混在を防ぐため空のディレクトリが必要です。再実行時は新しい出力先を指定してください。元アーカイブは変更しません。同じ出力先での同時実行は非対応です。読み取り失敗は記録して後続を処理し、最後に終了コード1を返します。失敗前に書き出されたファイルがあっても、その日を学習に使う前にレポートを確認してください。
