# 論文の構造・学習処理への対応（2026-10-17）

前日の監査で見つけた構造・学習処理の差を修正した。参照は Hirahara et al., *Cloud-Free Sea-Surface-Temperature Image Reconstruction From Anomaly Inpainting Network*, DOI: 10.1109/TGRS.2021.3111649、Table I–III、Fig. 6–8、式(6)–(9)。ここでいう対応は構造と処理の対応であり、原著と同一の数値結果や復元精度を達成したという意味ではない。

## 変更箇所

| ファイル | 変更 | 理由・対応 |
|---|---|---|
| `src/models/generator.py` | デコーダの128/64/32/16チャネル各段階に畳み込みを1層追加 | Table IIのConvolution ×2。最終1チャネル層を含め9層 |
| 同上 | エンコーダ最終e10のELUを除去 | III-Eの「encoder最終層を除きELU」に対応 |
| 同上 | 出力tanhを `clamp(-1,1)` に変更 | 出力のクリッピングという本文記述に対応。範囲内の値はtanhのように圧縮しない |
| 同上 | 月平均の9時刻への複製・fusion_projectionを除去 | 個別の1×1×1 Conv3dの後、9時刻特徴＋月平均1特徴を連結して10チャネルでencoderへ入力 |
| 同上 | アノマリー入力を `SST正規化差 / (2*anomaly_range/(max_temp-min_temp))` に変換し[-1,1]へクリップ | 偏差±anomaly_range℃を±1に揃える。マスク0の入力は0に戻す |
| `src/models/discriminator.py` | 64→128→256→256→256→512の6段階と4×4の最終畳み込みへ変更 | Table III。256×256→4×4→1×1。従来の空間平均による判定を除去。全畳み込みにspectral normalization |
| `src/datasets/unified_dataset.py` | 別時刻の学習画像から雲マスクをランダム選択 | 入力に追加遮蔽するための `random_cloud_mask`（1=保持、0=遮蔽）を返す。保存済みcloud_maskは1=雲なので反転する |
| `olds/datasets/himawari_patch_dataset.py` | 旧形式ローダーにも保存済みの別画像の雲マスク選択を追加 | 旧NPZ・フレーム形式の学習でも追加遮蔽を省略しない。1サンプルのみの場合は別の過去時刻を使う |
| `src/train/train_anomaly.py` | 追加マスクを入力SSTと入力有効マスクに適用 | 式(9)。target_sstとtarget_maskは変更しないので、人工的に隠した元観測画素にも式(7)の再構成損失がかかる |
| `src/train/train_average.py` | 月平均損失係数を `1-(epoch_index+1)/epochs` に変更 | 式(6)の現在epochを表示と同じ1始まりに統一。最終epochの月平均項は0。週平均項は残す |
| `src/train/train_anomaly.py`, `src/infer/reconstruct.py` | 学習・推論ともconfigから同じ偏差変換尺度を生成器へ渡す | 入出力尺度を一致させる。復元は引き続き「推定週平均＋偏差℃」 |
| `src/utils/checkpoint.py`, `main.py`, 学習・推論コード | モデル形式 `hirahara_tables_v2` を保存・検査 | 旧構造重みの誤使用を拒否。strictロードを使い、偏差尺度の不一致も拒否 |

識別器は最終sigmoidの前のlogitを返し、損失側で `BCEWithLogits` を使う。これはsigmoidとBCEを数値的に安定して組み合わせる方式で、sigmoidをさらにモデル末尾へ追加しない。既存の実画像=1・生成画像=0、G更新時はDを通して勾配を流す処理は維持する。

平均推定→平均重み固定→偏差学習→両重みで推論というメイン順序は変更していない。推論には人工雲マスクを追加しない。

## 論文からの実装上の解釈

本文は特徴をconcatすると記載するが、完全なテンソル実装は提示していない。本修正は時系列特徴9枚と月平均特徴1枚の連結（T+1チャネル）を採用した。

追加雲マスクについても時系列全体への細かな適用規則は明記されていない。本修正は1枚の実雲パターンを9時刻すべてへ共通適用する。平均生成器は追加遮蔽前の入力から週平均を推定して固定し、偏差生成器への入力だけを追加遮蔽する。元の観測マスクは保持し、観測されていない本来の雲下を正解として扱わない。

統合ローダーのマスク候補は、渡された学習manifestのサンプルが参照するフレームから作る。現在のターゲット時刻の画像を除き、別時刻の候補をランダム選択する。候補は各時刻について登録された最初の切り取り位置のマスク。抽選はtorchの乱数を使い、既存のseed/worker seed設定に従う。選んだパターンが晴天なら追加遮蔽が0になることもある。人工的な幾何図形への置換や雲量の再調整はしない。

偏差入力が±anomaly_range℃を超えた場合は範囲外をクリップするという実装方針を採用した。旧来のSST前処理範囲0〜35℃、GPVの選択、海域抽出、損失の有効画素平均によるMSE集約など、今回の監査対象外の処理は維持している。論文式の画素集約方法まで含む完全な数値一致は主張しない。

## 既存データ・重み

- 前処理済み `data/unified_sst` は再利用できる。256×256パッチと保存済みcloud_maskが必要。
- 旧checkpointは構造・正規化が違うため再利用不可。平均・偏差とも最初から学習する。
- 旧ファイルは削除しない。新しいrun-dirで実行する。
- 新しい識別器は論文の学習パッチ256×256を要求する。小さいサイズの合成訓練テストも256へ変更した。

サーバーへコードを反映後の動作確認例（ここでは実行していない）:

python3 main.py \
  --data-root /workspace/sst-inpainting-code/data/unified_sst \
  --run-dir /workspace/sst-inpainting-code/outputs/paper_v2_smoke_001 \

smokeは各段階1更新だけである。修正によって1更新で空間構造が復元される保証はない。新規学習の品質は十分な学習と独立期間の評価で確認する。学習/検証の期間分割・ブイ評価・全域復元は今回追加していない。
