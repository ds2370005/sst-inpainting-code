# ほぼ一定のSST出力のコード監査（2026-10-16）

対象はローカルの現在のコード。サーバーのチェックポイント・run.json・保存配列は取得していないため、添付画像の実行そのものを再現した検査ではない。本データでの学習は未実行。ネットワークや学習条件は変更せず、回帰テストを追加した。

## 結論

メインの工程順、平均モデルの重み受け渡し、SST復元の単位変換、GANの基本的な勾配接続には、今回調べた範囲で取り違えは見つからなかった。合成データではG/D双方のパラメータ更新を確認した。

現在のモデルは初期化直後にもほぼ定数の画像を出す。smokeは各段階1バッチ・バッチサイズ1であり、全23,788件の学習ではない。1回更新ではほぼ定数の出力が残ることを合成データで再現した。ただし、サーバーでの原因がこれだけだとは断定しない。

一方、論文の構造・学習手順との明確な差がある。したがって「エポックを増やせば論文再現として問題ない」とは言えない。

## 入出力経路

- `main.py`: preprocess → average → anomaly → reconstruct。anomalyにaverage/latest.pthを渡し、reconstructには両段階の重みを渡す。
- `src/train/train_anomaly.py`: 平均生成器をロードしeval・requires_grad=False・no_gradで固定。そこで計算した推定週平均をアノマリー生成器に渡す。
- `src/infer/reconstruct.py`: 平均生成器→アノマリー生成器→加算。推論で両checkpointをload_state_dictした後にevalを呼ぶ。
- 正規化SSTの復元式は `pred_weekly + pred_anomaly * (2*anomaly_range/(max_temp-min_temp))`。℃へ戻すと `推定週平均℃ + pred_anomaly*anomaly_range` になり、ここに単位の混同はない。
- `sampling.py`のframesは古い→新しい順。ローダーのtarget_sstと可視化のlatest frameはともに末尾のフレーム。
- G更新のD入力はdetachしない。D更新時のfakeだけdetachする。Dの生logitとBCEWithLogitsの組み合わせは整合しており、明示的sigmoidがないこと自体は不具合ではない。

## 論文との不一致（今回の定数出力の原因と確定したものではない）

照合元：Hirahara et al., *Cloud-Free Sea-Surface-Temperature Image Reconstruction From Anomaly Inpainting Network*, DOI 10.1109/TGRS.2021.3111649。手元PDFの4ページ Table I/II・Fig.8、5ページ式(7)〜(9)、6ページ Table III。

1. **デコーダの畳み込みが4層少ない。** Table IIでは128/64/32/16チャネルの各ブロックがConvolution×2。`EncoderDecoder2D`は各ブロック1層ずつで、最終1チャネル層を含めて5層。論文は9層。
2. **識別器の末尾が異なる。** Table IIIは64→128→256→256→256→512（5×5, stride 2）→1（4×4, stride 1）。現行は512チャネル層がなく、256→1の5×5畳み込みと空間平均でスカラー化。
3. **学習用の追加雲マスク m_rand がない。** 論文は他の学習SSTから採った雲マスクで観測部分を追加遮蔽し、元の観測値を損失の参照に使う。現在のローダーは元の観測マスクだけを渡し、train_anomalyもそれをそのまま使用。雲下補完を学習する重要な条件が欠ける。
4. **出力のtanhとエンコーダ末尾のELU。** 論文は出力を[-1,1]にclip、エンコーダ最終層にはELUを使用しないと記述。現行はtanhおよびe10にもELU。これだけで今回の平坦化が説明できるわけではない。
5. **平均生成器の融合方式。** Fig.8と本文は2枝の特徴をconcatしてencoderへ渡す。現行は月平均特徴を9時刻へrepeat後、追加の1×1×1 fusion_projectionで2枝を1チャネルへ圧縮する。図だけからconcatの全次元仕様は断定できないが、この追加圧縮は論文に明示されていない。
6. **偏差入力の尺度は要整理。** 現行の入力差分は正規化SST同士の差（℃差/17.5、現在の0〜35℃設定）で、出力偏差の尺度は℃差/5。学習・推論で同じ処理なので入出力経路の取り違えではないが、偏差±5℃を±1とする論文の正規化を入力にも揃えるなら、入力差分を `anomaly_to_sst_scale` で割る必要がある。既存checkpointの意味が変わるので、互換性を考慮せず変更しない。

構造変更はcheckpointのキー・形状を変更する。修正前checkpointを修正版に部分ロードして同じ学習結果として扱ってはいけない。
